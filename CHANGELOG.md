# Changelog

## 2.0.0 — Multi-version release (1.20.5 – 26.3+)

- Added full multi-version support covering Minecraft 1.20.5 through 26.3+ using dynamic data pack overlays.
- Added `overlay_1_20_5` for Minecraft 1.20.5 – 1.20.6 with legacy tags, plural recipes, and stringified item components.
- Added `overlay_1_21_2` for Minecraft 1.21.2 – 1.21.4 with updated recipe structure and singular resource paths.
- Added `overlay_1_21_5` for Minecraft 1.21.5 – 1.21.11 – 26.3+ with structured item components.
- Updated pack metadata format range: 41 to 150 (`supported_formats`).
- Pre-packaged ready-to-use releases in both English and Russian.

## 1.0.0 — Minecraft 1.21.11 release

- Added per-player lactose reactions, tolerance, adaptation, and anti-spam streaks.
- Added soft, default, spicy, and challenge configurations.
- Added lucky digestion, dairy disaster, and cow-witness events.
- Added lactose-free milk and a normal crafting-table recipe for lactose-free cake.
- Added dairy-food behavior, advancements, statistics, leaderboards, admin tools, and uninstall support.
- Fixed the advancement background identifier for Minecraft 1.21.11.
- Standardized pack metadata to data pack format 94.1.
