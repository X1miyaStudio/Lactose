# Lactose — Modrinth Listing

## Summary

Milk becomes a survival system with reactions, tolerance, events, achievements, and lactose-free recipes.

## Project Settings

- Type: Data Pack
- Categories: Food, Game Mechanics, Utility
- Environment: server-side required, client-side unsupported
- Game version: Minecraft Java 1.21.11
- Dependencies: none
- License: MIT

## Description

Lactose makes milk a risky habit. Drinking milk builds a temporary reaction; drinking again too quickly raises its level and can trigger additional dairy events. Recovering gradually improves tolerance, while optional challenge mode makes milk a sharper survival tradeoff.

The datapack includes soft, default, and spicy configurations, a custom advancement tree, statistics, leaderboards, lactose-free milk, and a lactose-free cake crafted normally at a crafting table.

## Installation

Place the ZIP in the world's `datapacks` directory and run `/reload`.
